# Agent brand assets

These files are used only to identify the runtime/provider shown in HIRDA. They are not HIRDA branding and do not imply sponsorship or endorsement.

- `claude.svg` — Claude mark from Simple Icons v16. The Simple Icons Claude entry cites Claude's official app icon / website SVG as its source.
- `openai.svg` — OpenAI mark copied unchanged from the official `openai/openai-agents-python` repository (`docs/assets/logo.svg`). Use is subject to OpenAI's current brand guidelines.
- `hermes.jpg` — Hermes / Nous Research `nous-girl` BrandMark from the official `NousResearch/hermes-agent` repository (`apps/desktop/public/nous-girl.jpg`). Hermes Desktop's design guide identifies this image as its BrandMark.

Do not recolor, redraw, stretch, mask, or incorporate these marks into the HIRDA product mark. HIRDA may use provider-owned brand colors on the icon container while leaving the mark itself unchanged.

Current container treatments:
- Claude: Anthropic/Claude primary accent orange `#d97757`.
- Codex/OpenAI: black container with the supplied white OpenAI mark.
- Hermes: Hermes default-skin gold/bronze `#FFD700` / `#CD7F32` around the unmodified Nous BrandMark.
