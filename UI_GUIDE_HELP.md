# UI Guide + Hover Help

The Guide is now ChatGPT-first instead of admin-first.

## Daily workflow
1. Open ChatGPT.
2. Tell ChatGPT which workspace to use, for example `Use workspace nova-oracle` / `ใช้ workspace nova-oracle`.
3. Continue naturally: inspect status, list panes, edit code, run tests, and commit after review.
4. To switch projects, tell ChatGPT to switch workspace; do not manually cross-switch Serena active projects.

## UI role
- ChatGPT = working surface.
- MCP Studio UI = control surface for sessions, workspaces, ingress, isolated Serena instances, and troubleshooting.

## Help
- Common commands have copy actions.
- Registered workspace rows expose a localized `Copy ChatGPT command` action.
- Hover/focus help remains available for technical terms and important controls.
- Admin setup is intentionally secondary and collapsed.
