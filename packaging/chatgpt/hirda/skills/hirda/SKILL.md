# HIRDA

- Use the connected HIRDA tools for tasks involving HIRDA workspaces or capabilities.
- Check the available tools and their descriptions before choosing one; ask before consequential actions.
- Complete ChatGPT's OAuth authorization for your own account when prompted. Sign-in is handled by HIRDA; this package contains no private authentication values.
- If the connection is unavailable or a tool is missing, say so and explain what is needed.
